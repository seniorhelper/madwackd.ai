# Producer Z walk frames (stage polish, 2026-11-08)

Full-body claymation frames of Producer Z for the home / Genie page stage (`assets/stage.js` walks him by
swapping these four stacked images). Original renders of Madwackd's own character, made from `assets/z/z-hero`
as the style reference. AI-generated stills (Gemini 3.1 Flash Image on Vertex AI, project `madwackd-studio`,
same route as `../genie/README.md`), keyed off a flat green background with a border-connected flood fill so
his green laces and the green clapstick stripe survive.

| File | Use |
|---|---|
| z-walk-1.webp | stride, front heel down |
| z-walk-2.webp | passing pose (also his standing frame) |
| z-walk-3.webp | opposite stride |
| z-cheer.webp | megaphone up, free arm out (while he talks) |
| *-280.webp | phone size (half) |

All 517x560 (280-tall halves), transparent, facing right; the page mirrors them to walk left.

**Cost:** 5 calls x $0.101 = **$0.51 estimated** (one retake of the opposite stride, kept the megaphone in the same hand) (cap was $1.50). Rows in `COST-LEDGER.csv`. Not checked against the Google bill.
